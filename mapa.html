Leaflet es una librería open-source de JavaScript para crear mapas interactivos en la web. Es ligera, fácil de aprender y compatible con múltiples proveedores de mapas como OpenStreetMap, Google Maps o Topographic Maps.

- Conocimientos básicos de HTML, CSS y JavaScript
- Un <div id="map"> con altura definida en CSS
- Incluir leaflet.css y leaflet.js en tu página

  • Añadir marcadores y rutas
  • Panel lateral con lugares turísticos

  • Geolocalización del usuario

  • Ligero y rápido (pesa alrededor de 40 KB).
  • Compatible con dispositivos móviles y pantallas táctiles.
  • Sistema de capas (mapas base + elementos superpuestos).
  • Amplia variedad de plugins desarrollados por la comunidad.
  • Altamente personalizable (estilos, íconos, popups, polígonos).
  • Código abierto y gratuito, con integración a OpenStreetMap.

Estas son las funciones de Leaflet utilizadas para crear e interactuar con los marcadores del mapa.

Crea un nuevo marcador en la posición indicada por las coordenadas [lat, lng].
Recibe: las coordenadas y parámetros opcionales de configuración (por ejemplo, ícono o título).
Devuelve: una instancia del marcador que puede añadirse al mapa o encadenarse con otros métodos.

Añade el marcador al mapa actual.
Recibe: la instancia del mapa (map).
Devuelve: el mismo marcador, lo que permite encadenar métodos.

Asocia una ventana emergente (popup) al marcador.
Recibe: el texto o HTML que se mostrará y parámetros opcionales de diseño.
Devuelve: el marcador con el popup vinculado.

Crea una etiqueta flotante que aparece al pasar el cursor sobre el marcador.
Recibe: el texto o HTML que mostrará y opciones de visualización.
Devuelve: el marcador con el tooltip vinculado.

Centra y ajusta el nivel de zoom del mapa en una ubicación específica.
Recibe: coordenadas ([lat, lng]) y el nivel de zoom.
Devuelve: la instancia del mapa con la nueva vista aplicada.

Métodos adicionales para manipular popups.
popup(): crea un popup vacío.
setLatLng(): cambia su posición en el mapa.
setContent(): actualiza el texto o HTML del popup.
openOn(map): abre el popup sobre la instancia del mapa especificada.

Dibuja una línea o ruta conectando una secuencia de coordenadas en el mapa.
Recibe: una lista de puntos [[lat1, lng1], [lat2, lng2], ...] y parámetros opcionales (color, grosor, opacidad, etc.).
Devuelve: un objeto de tipo Polyline que puede añadirse al mapa con .addTo(map).

  • Vs Google Maps: Leaflet es gratuito, flexible y sin restricciones de uso.
  • Vs Mapbox GL JS: más ligero y simple, ideal para la mayoría de proyectos web.
  • Vs librerías pesadas: menor consumo de recursos y mayor velocidad de carga.
  • Ventaja clave: gran comunidad que aporta plugins y soporte constante.

  • Flickr: utiliza Leaflet para mostrar mapas en fotos con geolocalización.
  • Foursquare: implementa Leaflet en sus productos web para mapas interactivos.
  • Craigslist: integra Leaflet en su plataforma de clasificados.
  • Cartier: su sitio de tiendas usa Leaflet para mapas de localización.
  • Gobiernos y servicios públicos: emplean Leaflet en portales de cartografía y datos geográficos.

- La geolocalización solo funciona en HTTPS o localhost
- Recuerda atribuir a OpenStreetMap al usar sus tiles
- Leaflet es ideal para demos, proyectos académicos y prototipos rápidos

Leaflet permite crear mapas interactivos de forma sencilla y flexible. Gracias a su comunidad y compatibilidad con proveedores de mapas, se convierte en una herramienta perfecta para aplicaciones web modernas.
